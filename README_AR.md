# Anghami AI Bridge — Android Beta 0.1.0

## الحالة
نسخة Android تجريبية قابلة للبناء والاختبار، وليست تكاملاً كاملاً مع حساب Anghami.

## ما يعمل
- واجهة عربية داكنة بلمسات ذهبية.
- فحص وجود تطبيق Anghami.
- فتح الموقع الرسمي وفتح رابط بحث.
- شاشة تشخيص وحدود واضحة.

## ما لا يعمل بعد
- لا يوجد اتصال فعلي بـ OpenAI API.
- أزرار التشغيل/الإيقاف/التالي/السابق توضيحية ولا ترسل أوامر للمشغل.
- إدارة قوائم حساب Anghami تتطلب API رسمي وصلاحيات معتمدة.

## استخراج APK تلقائياً
1. افتح تبويب Actions في GitHub.
2. اختر Build Android APK.
3. اضغط Run workflow.
4. بعد نجاح البناء افتح نتيجة التشغيل ونزّل Artifact باسم Anghami-AI-Bridge-debug.
5. فك ZIP وثبّت APK على هاتف Android.

## الأمان
لا تدخل كلمة مرور Anghami أو رموز جلسة الدخول. إضافة OpenAI لاحقاً يجب أن تتم عبر خادم وسيط آمن، لا بوضع مفتاح API داخل APK.
